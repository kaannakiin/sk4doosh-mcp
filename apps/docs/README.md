# @liaiso/docs

The liaiso documentation site. TanStack Start (Vite) + Mantine + Tailwind CSS.

```bash
pnpm --filter @liaiso/docs dev     # http://localhost:5180
pnpm turbo run build --filter=@liaiso/docs
```

## Content

Pages live under `src/content/<product>/<mode>/*.md`; the tree has two axes (product line ×
Diátaxis mode). The filename gives the order and the slug, the first `#` line gives the title
(`http-catalog/00-introduction.md` → `/docs/http-catalog/introduction`). The sidebar is generated
by `src/lib/content.ts`; the product list comes from `src/content/products.json`.

`pnpm --filter @liaiso/docs validate` enforces the structural rules (mode folder names, product
registration, unique slugs, `# Title`, internal link targets). `pnpm lint` runs it too.

Site content and UI strings are written in **English** — this site is liaiso's public face. `packages/http/spec/`
is in English too, because the site links to it as its normative source. There is no i18n layer: one
language, no drift.

The binding writing conventions — the Diátaxis taxonomy, one page per mode, reference pages
generated rather than hand-written, RFC 2119 keywords confined to the spec — live in
[WRITING.md](WRITING.md) (not published on the site).

## Style layers

`src/styles/app.css` fixes the layer order:

```css
@layer theme, base, components, mantine, utilities;
```

Tailwind's preflight (`base`) comes before Mantine, so it never overrides Mantine's component
styles; Tailwind's utilities (`utilities`) come after Mantine, so `<Button className="mt-4">`
works. This is also why `@mantine/core/styles.layer.css` is imported — never both it and
`styles.css` at once.

## Generated file

`src/routeTree.gen.ts` is generated by TanStack Router and committed to the repository; the
`check-types` task does not depend on `build`, so a clean checkout needs it present.
