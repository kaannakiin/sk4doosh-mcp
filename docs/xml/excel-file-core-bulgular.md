## Güncel durum ve başlangıç önceliği

Tablolardaki **CI geçti** durumu beş native hedefin Node 22/24 testlerini ve paket doğrulamasını kapsar. **Sınırlılık belgeli; takip açık**, kabul edilen eksik metadata desteğini belirtir. Başlangıç bulguları ve kabul sözleşmeleri denetim izi için korundu; eski satır numaraları güncel kod konumu değildir.

Aşağıdaki dört sınıf uygulama öncesi incelemenin değerlendirme ölçütleridir:

- **Doğrulandı:** mevcut kaynak ilgili koşulu veya eksik kontrolü açıkça gösteriyor. Çalışma zamanı sonucu ayrıca test edilmeli.
- **Koşullu:** kök neden görünür; etki özel dosya, platform, saldırgan erişimi veya bağımlılık davranışı gerektiriyor.
- **Tasarım tercihi:** davranış mevcut; tek başına hata değil. Sözleşme açıklığı veya farklı ürün kararı gerekiyor.
- **Doğrulanamadı:** mevcut kanıt kesin iddiaya yetmiyor. Kaynak taramasında test bulunmaması, bütün dolaylı kapsamın yokluğu anlamına gelmez.

P1: güvenlik sınırı, hizmet sürekliliği veya sessiz veri bozulması. P2: koşullu doğruluk/performans sorunu veya yanlış hata. P3: dokümantasyon ve hedefli test açığı. Öncelik CVSS puanı değildir.
